# u3 : a cellular automaton based sandbox game.

This is a top down scrolling multiplayer cellular automaton based sandbox game. It is project 1 of the game design class CS 447 at WSUV.

It is currently still under development, however the server and client programs are sufficiently finished to allow the core / essential / base functionality of the game to be played, and its pretty fun too.

This repo holds both the client and server code.
